# internet.io — landing page

A 1:1 static build of the internet.io marketing landing page from Figma: *"Ask once. See how every AI thinks."*

Plain HTML, CSS and JS with no build step. Inter and Roboto come from Google Fonts, and the colours and tokens come from the Figma file (`#2979ff` blue-600, the neutral scale, the Hero shadow).

**Live:** https://devfawaz.github.io/internetio-website/

## Interactions
- Model chips marquee that loops and pauses on hover
- Hero search input that cycles through example prompts
- Testimonial slider with arrow and dot controls
- Responsive layouts for desktop, tablet and mobile

## Run locally
```bash
npx serve .
```
